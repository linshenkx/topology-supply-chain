## 2. 本次完成：SKU/BOM 日常操作

### SKU

- 列表提供明确的“查看详情”入口。
- 详情展示物料属性、单位换算、容差、状态和最近审批结果。
- 被驳回且仍为草稿的 SKU 可修改后重新提交；原 SKU ID 和编码保持不变，并生成新的审批、审计及幂等记录。
- 待审批、已审批或不满足状态条件的 SKU 不能借重提入口修改。
- 清空采购单位时会停用原有效单位换算；换算变更在审计中保留前后值。
- 工厂角色读取主数据时不暴露内部审批说明等管理信息。

### BOM

- 列表提供明确的“查看详情”入口，详情以弹窗呈现，不依赖整行隐藏交互。
- 详情展示组件、用量、核心配件、偏差和有效区间。
- 现有 BOM 可复制为新版本；用户必须重新填写版本号和生效日期。
- 提交继续复用现有 `create_bom`、审批、版本冲突和重叠校验，不新增另一套写入流程。

## 6. 建议接手顺序

1. 将本地 `main` 推送到正式私有远端，并记录远端 SHA。
2. 如需继续查看效果，按本地 Compose 用 HTTP 启动，检查 SKU 详情、驳回重提、BOM 详情和复制新版本。
3. 经确认后更新 UAT；部署前备份当前配置和数据库，部署后仅做对应页面的简洁回归。
4. 由项目方确认 Excel、工作台和工厂协同的首期范围，再分别排期，避免把演示页面自动解释为完整业务需求。
5. 后续缺陷按“阻塞使用 / 不阻塞使用”分类；非阻塞问题先记录，不因测试临时扩大业务范围。
